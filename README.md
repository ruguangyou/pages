# ruguangyou.github.io

This repository is the personal GitHub Pages site for Ruguang You.

The site is a single static page (`index.html` and `styles.css`) published from the repository root at [https://ruguangyou.github.io/](https://ruguangyou.github.io/). The stylesheet link is a same-directory path. A `.nojekyll` file keeps GitHub Pages from running a Jekyll build.
