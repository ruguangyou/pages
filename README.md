# pages

This repository is the personal GitHub Pages site for Ruguang You.

The site is a single static page (`index.html` and `styles.css`) published from the repository root at [https://ruguangyou.github.io/pages/](https://ruguangyou.github.io/pages/). Asset paths are relative so they resolve under `/pages/`. A `.nojekyll` file keeps GitHub Pages from running a Jekyll build.
